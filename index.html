This page is a static site, so it can run on GitHub Pages without a server, database, or paid hosting.

GitHub Pages: step by step

  1. Create a GitHub account and a new public repository. For the cleanest URL, name it your-username.github.io.
  2. Upload this file as index.html in the repository root. Commit the change.
  3. On the first submission, FormSubmit will send an activation email to adirbarhanin5@gmail.com. Confirm it once; later requests will be delivered automatically.
  4. Open Settings → Pages. Under “Build and deployment”, choose Deploy from a branch, select main and /(root), then click Save.
  5. Wait for the deployment check to finish. Your site will be available at https://your-username.github.io.
  6. For a custom domain, add it under the same Pages screen. GitHub will create a CNAME file for you; keep it committed.

Israeli domain options

  1. A free .org.il domain is not normally offered by GitHub. Israeli domains are registered through an ICANN/ISOC-IL accredited registrar, usually for an annual fee.
  2. .org.il is intended for organizations. Check the registrar’s eligibility rules and current pricing before purchase; there is no guaranteed universal “free” option.
  3. Truly free fallback: use your-username.github.io, or a free subdomain from a reputable provider. Avoid “free domain” offers that require payment details or forced ads.
  4. To connect a purchased domain, set the apex A records to 185.199.108.153, 185.199.109.153, 185.199.110.153, and 185.199.111.153. Set www as a CNAME to your GitHub Pages hostname.
  5. DNS can take up to 24–48 hours to propagate. Enable “Enforce HTTPS” in GitHub Pages after the certificate becomes available.
